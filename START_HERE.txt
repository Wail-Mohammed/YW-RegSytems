FIRST SETUP ON ANOTHER COMPUTER
Install Node.js and MySQL. In the extracted project folder run npm ci.
Use .env.example with your own local MySQL connection, then npm run db:setup.
Alternatively, npm run local:setup creates a separate local MySQL instance;
npm run local:start starts that instance and the app. See README.md for ports.

TESTS
npm test                   (7 backend-validation scenarios)
npm run test:integration   (12 isolated MySQL workflow scenarios)
npm run test:browser       (9 actual Chrome browser checks)
npm run check              (JavaScript syntax checks)
Integration/browser tests need local MySQL credentials and create their own
temporary databases. Chrome is required for browser checks and PDF generation.

BEFORE CANVAS SUBMISSION
1. Record/upload the demonstration and obtain a link the professor can view.
2. Confirm the database-class team ID. Web_App_Assignment.pdf page 3, Section 6,
   item 4 requires the report filename teamXY.pdf, where XY is that ID.
3. Put teamId and demoUrl in docs/submission.json. Keep the two authors' names.
4. Run npm run report. It generates team<ID>.pdf and updates the README demo
   link. Without an ID it keeps the filename report.pdf and marks it pending.
5. Submit the source/SQL files, required PDF, and demo link as instructed.
